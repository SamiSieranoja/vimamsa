❙Welcome to Vimamsa❙
A Vim-inspired text editor. This page is always in Help ▸ Introduction.

◼ Modes
Command mode: keys move the cursor and edit. The badge at the bottom right shows the mode.
Insert mode: keys type text. Enter it with {key:C:mode.insert}, leave it with {key:I:mode.prev}.
Visual mode: select text, {key:C:mode.visual}.
(ctrl! = press and release ctrl alone, with no other key)

◼ The essentials
Open a file      {key:file.open}
Find a file      {key:file.finder}
Save             {key:buf.save}
Search           {key:search.buf}
Undo             {key:undo.last}
Command line     {key:mode.cmdline}
