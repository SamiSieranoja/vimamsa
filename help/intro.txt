❙Welcome to Vimamsa❙
A Vim-inspired text editor. This page is always in Help ▸ Introduction.

◼ Modes
⦁COMMAND⦁: keys move the cursor and edit. The badge at the bottom right shows the mode.
⦁INSERT⦁: keys type text. Enter it with {key:C:mode.insert}, leave it with {key:I:mode.prev}. Works somewhat like editing in notepad + some bash/emacslike bindings.
⦁VISUAL⦁: select text, {key:C:mode.visual}.

(⦁ctrl!⦁ = press and release ctrl alone, with no other key)

◼ The essentials

⦁(In command mode:)⦁
To insert mode        {key:C:mode.insert}
To visual mode        {key:C:mode.visual}
Back to command mode  {key:I:mode.prev}
Open a file           {key:C:file.open}
Save                  {key:C:buf.save}
Search                {key:C:search.buf}
Undo                  {key:C:undo.last}
Moving ⦁← → ↑ ↓⦁        ⦁h l k j⦁
Next/Prev word        ⦁w b⦁
EasyJump              ⦁s⦁
